# SFW merch, v2

Built by `tools/merch_v2.py` from the Foundation's own brightfield microscopy (`assets/microscopy/cutout-*.png`).
Each cutout is converted to a one-ink engraver's line screen (23 lines per inch, thinnest line 2.5 px = 0.6 pt);
the organism is exactly as photographed, nothing drawn or generated.
Type: Montserrat 600/700 and EB Garamond 400, upright, converted to outlines. No captions or source lines on product.

| Design | Plate | Files |
|---|---|---|
| POWERED BY PROTOZOA | cutout-3 (ciliate) | `print-files/tee-front-powered-by-protozoa-{light,dark}.png` |
| BE THE MYCELIUM YOU WANT TO SEE IN THE WORLD | none yet, type only (no hyphae in our microscopy library) | `print-files/tee-front-be-the-mycelium-{light,dark}.png` |
| IN THE END, AREN'T WE ALL JUST A BUNCH OF MICROBES? | cutout-3, cutout-2 (amoeba), cutout-1 (testate amoeba) | `print-files/tee-front-bunch-of-microbes-{light,dark}.png` |
| HAVE YOU TESTED IT UNDER THE MICROSCOPE YET? | cutout-1 (testate amoeba) | `print-files/tee-front-under-the-microscope-{light,dark}.png` |

Light = Soil Brown + Food Web Green (Desert Dust). Dark = Organic Cream + Light Green (Khaki, Black).
Tee files are 3600 x 4800 px, 300 dpi, transparent; art starts at the top of the file.
Earlier code-drawn designs are in `_superseded-v1/`.
