# India free images

Free-to-use images from Unsplash for India posts. Linnea uploads these.
Use only files in this folder for India visuals.

## Rules that travel with this folder

- **Never present these as Soil Food Web workshop photographs.** They are
  stock pictures of other places, other people, other soil. No caption, alt
  text or story frame may imply the Foundation took them or that they show the
  Accelerator Workshop, the Save Soil farm, or anyone teaching on it.
- **Credit the photographer in small text on any story that uses their photo.**
  The story templates in `content/india/countdown-stories/` carry a
  `.credit` line for exactly this. Format: `Photo: [Name] / Unsplash`.
- **Record every file in `CREDITS.md`** when you upload it: filename,
  photographer, Unsplash URL. A file with no row in that table is not cleared
  for use.
- No photograph of a recognisable person doing something the caption does not
  support. A stranger in a field is not a workshop attendee.

## Why this folder exists

`INVENTORY.md` flags the licence gap across the picture library: seven
photographs sit in `assets/photo/openly-licensed/` with an empty credits
register. This folder does not repeat that mistake. The credits table is part
of the folder, not a thing to add later.
