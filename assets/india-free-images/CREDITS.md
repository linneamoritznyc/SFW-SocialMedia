# Credits

Every image in this folder gets a row. Fill it in at upload time, not later.
Unsplash images are free to use under the Unsplash Licence; crediting the
photographer is asked for rather than required, and this repository treats it
as required.

| Filename | Photographer | Unsplash URL |
| :-- | :-- | :-- |
| _(none uploaded yet)_ | | |

## How to fill a row

1. `Filename` exactly as uploaded, including the extension.
2. `Photographer` as Unsplash shows the name on the photo page.
3. `Unsplash URL` the photo page, `https://unsplash.com/photos/...`, not the
   direct image file and not a search result.

Then put `Photo: [Photographer] / Unsplash` in the `.credit` line of any story
that uses the file.
