## How to use this file

**It is a bank, not a style guide.** `sop/brand-voice.md` is where the rules live,
when it exists. This is a list of sentences that already earned their place.

**Three tests before a line goes public:**

1. **Did someone here actually say it?** Every line above did. A line invented for
   a campaign does not belong in this file.
2. **Does it survive being read by a stranger?** "We freely exchange information
   nutrients" reads as a shared joke inside the organisation and as something
   else outside it.
3. **Is it internal?** Two of the fourteen are marked internal only. The
   poop-loop is funny and it is not going on a homepage.

**When a new line appears, add it here the same day.** The reason this file exists
is that fourteen good lines sat in meeting transcripts for years.
