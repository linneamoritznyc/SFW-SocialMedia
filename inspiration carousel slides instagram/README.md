# Inspiration: Instagram carousel slides

Reference images for seamless (panoramic) carousels. Drop the image files in this folder.

| Reference | What to take from it |
| :-- | :-- |
| Will Khoury, "Create Seamless Instagram Carousel in Photoshop" | One full-bleed photo strip; smaller photos with thin white frames layered on top and overlapping the slide seams; very restrained type. |
| "How To Guides, explanatory carousel" (Canva template) | Alternating dark and light slides, one big bold condensed headline per slide, a plant cutout that crosses a seam, small logo top right on every slide. |
| "Instagram carousel for travel" (Canva template) | White strip on a beige ground, photos of different sizes placed across the seams, thin vertical divider lines, a handwritten script accent, small captions. |

Shared rules: design on one wide canvas; put something on every seam so a swipe completes it; keep one grid for text.
